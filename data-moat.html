LOOP

DATA IMPROVEMENT LOOP

학습할수록 더욱 정교해지는
데이터 선순환

1. 실제 교육 현장 상호작용

실제 교육 현장에서 발생하는 아동의 발화 및
학습 상호작용 데이터를 실시간으로 수집합니다.

2. 비식별화 · 정제 · 분류

수집된 데이터를 비식별화, 정제, 분류하여
안전하고 신뢰할 수 있는 학습 데이터로 가공합니다.

3. ELM과 평가 엔진 고도화

정제된 데이터를 바탕으로 아동 특화 언어모델(ELM)과
평가 엔진을 지속적으로 고도화합니다.

4. 성능 검증 및 제품 반영

고도화된 모델의 성능을 검증하고
실제 제품과 서비스에 안전하게 반영합니다.

5. 새로운 학습 데이터 축적

실제 교육 현장에서 축적된 데이터는
ELM과 평가 엔진의 고도화로 이어지고,
검증과 제품 반영을 거쳐
다시 더 나은 학습 경험과 새로운 데이터로 연결됩니다.
