# ELEA Bilingual Release — ENG Default

## Language structure
- Default English pages: `index.html`, `data-moat.html`, `digital-human.html`, `learning-experience.html`
- Korean pages: `index-ko.html`, `data-moat-ko.html`, `digital-human-ko.html`, `learning-experience-ko.html`
- Header `KOR | ENG` switches between the matching page in each language.

## MEET ELEA video files
Place the following MP4 files in `assets/video/` using the exact filenames below.

- English: `meet_elea_eng.mp4`
- Korean: `meet_elea_kor.mp4`

The MP4 files are intentionally not included in this package.

## Privacy popups
- English default pages open the English Privacy Policy and Children’s Privacy Policy.
- Korean pages open the Korean versions.
